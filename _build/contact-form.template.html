How this gets routed

Rules the endpoint applies — proposals for the developer, not built behaviour.

1To the property's agent. property_id decides the queue. Each property has assigned agents; if none is on duty it falls back to the property's contact_email.
2Never only email. The notification is a record in the system with a claim action, so an enquiry can't be lost in one person's inbox.
3Unclaimed escalates. Nothing claimed within 2 working hours re-notifies the property manager; 8 hours goes to the group inbox.
4Flags are computed, not typed. Party size, peak weeks, repeat-guest match and agent enquiries are derived on arrival.
5Auto-reply is immediate; the human reply is not. The guest hears back in seconds either way — which is what stops them enquiring at three other lodges while they wait.
