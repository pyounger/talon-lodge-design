Access & Roles

Define who can use which apps. Each role is granted a set of apps; the hub's “View as” switcher (top bar) shows only that role's apps. Give a bartender just Beverages, Orders & Photos; give managers everything. Changes apply to the hub immediately.

Maps to Andy's schema → roles + role_app (role → allowed app) + user.role_id. Stored in talon_roles_v1; the app list comes from talon_app_catalog_v1 (written by the hub). In production this is enforced server-side per authenticated user.
