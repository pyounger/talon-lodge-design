Fish Processing

At the end of each fishing day, log the group's catch once. The engine yields the filet weight per species (count × avg weight × recovery%), totals the day, and splits it into however many take‑home shares the group wants — one named guest per share. Each share's poundage lands on that guest's own record, so it rolls up per individual for the trip.

Maps to Andy's schema → fish_catch (trip_id, group, catch_date, species_id, count, avg_weight, recovery_pct) + fish_catch_split (catch_date, share_index, person_id, lbs) + fish_processing (trip_id, person_id, ship_method (carryon|fedex|none), fedex_date, smoke, note) + fish_payment (trip_id, payer_person_id, stripe_payment_method_id — no PAN stored). Every share row references a person — the catch funnels to the individual.
